# Hora-pico

Site estático para o estudo da demanda da hora-pico. Continua o [projeto de capacidade aeroportuária](https://github.com/airportlab/airport-capacity). A hora usada lá é a 30ª hora-relógio. O cálculo dos métodos ainda não está neste passo.

## Como rodar

```bash
npm install
npm run dev
```

Build estático: `npm run build`. Pré-visualização: `npm run preview`.
